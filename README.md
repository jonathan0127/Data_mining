## 執行

本專案使用uv管理。

### 1. 安裝環境


```bash
uv sync
```


### 2. 執行主程式


```bash
uv run main.py
```

在終端選擇：
1. 分類演算法：`1. SVM` 或 `2. Random Forest`
2. 分群演算法：`1. KMeans` 或 `2. DBSCAN`

也可在 `params.py` 中直接調整前處理選項：
- `use_pca`: 是否啟用 PCA 降維
- `use_standardlize`: 是否啟用特徵標準化
- `datatype`: 資料集選擇 (`'A'` 或 `'B'`)
- `use_oneclass_svm`: 是否使用 One-Class SVM 檢測未知樣本

## 實驗結果

## 消融實驗結果與分析

透過啟用/關閉**特徵標準化**、**PCA 降維**與 **One-Class SVM 新穎檢測**，評估各模組對模型**已知類準確率**與**整體準確率**的影響。

> **說明**：
> - `✓`：啟用該模組。
> - `-`：未啟用。
> - **已知 (Known Acc)**：測試集中已知類別樣本的分類準確率。
> - **整體 (Overall Acc)**：包含已知分類與未知樣本 K-Means 分群映射後的總體準確率。
